# AI气象领域顶刊论文复现与改进：8周任务安排

## 8周安排：先闭环，再扩展

### 第1周：环境、论文阅读、任务理解

- 重点：确保所有人跑通同一套数据流程。
- 当前状态：已完成阶段性梳理，完成论文初步精读、仓库结构理解与任务认知。

### 第2周：数据读取、样本构造、可视化

- 重点：确保所有人跑通同一套数据流程。
- 计划目标：
  - 理清数据读取入口与数据格式
  - 完成样本构造流程理解
  - 跑通基础可视化与数据检查流程

### 第3-4周：CNN、ConvLSTM、SimVP等基线复现

- 重点：复现可靠，而不是盲目调参。
- 计划目标：
  - 至少跑通一个基线模型闭环
  - 梳理训练、验证、测试与结果保存流程
  - 比较不同基线在任务上的表现差异

### 第5周：统一评价、结果复核、检查数据泄漏

- 重点：复现可靠，而不是盲目调参。
- 计划目标：
  - 统一评价指标与实验对比方式
  - 复核关键实验结果
  - 检查样本划分、输入构造和流程中是否存在数据泄漏风险

### 第6-7周：方法改进、消融实验、误差分析

- 重点：做出可解释的改进和完整交付。
- 计划目标：
  - 设计小规模、可验证的改进点
  - 完成必要的消融实验
  - 从数值误差、空间结构和案例结果等角度分析模型表现

### 第8周：代码整理、报告、PPT和答辩

- 重点：做出可解释的改进和完整交付。
- 计划目标：
  - 整理代码仓库与实验材料
  - 输出实习报告与结果总结
  - 准备答辩 PPT 与展示材料

## 备注

- 整体推进原则：先跑通闭环，再逐步扩展。
- 前期重点是流程打通和结果可信，中后期重点是解释清楚改进点与实验结论。
